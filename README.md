# 📸 Gallery Project

This Gallery Project is a mini React application built as part of my React learning journey. In this project, I applied the concepts I recently learned, including React Hooks (`useState` and `useEffect`), API fetching with Axios, component-based architecture, and state management.

The application fetches images from the Picsum Photos API and displays them in a responsive gallery with pagination, allowing users to browse through different pages of images.

### 🚀 Features

* Fetches images from the Picsum Photos API
* Pagination (Previous & Next)
* Responsive gallery layout
* Reusable React components
* Loading state while fetching data
* Built with React, Axios, and Tailwind CSS

### 🛠️ Technologies Used

* React
* JavaScript (ES6+)
* Axios
* Tailwind CSS
* Picsum Photos API

### 📚 What I Learned

* Managing state using `useState`
* Fetching data with `useEffect`
* Making API requests using Axios
* Passing data through props
* Creating reusable components
* Handling asynchronous operations and conditional rendering

This project is a part of my React learning journey, where I practice new concepts by building small, hands-on applications.
